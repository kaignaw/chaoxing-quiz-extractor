# 超星学习通 - 随堂练习题目与答案提取器

一个用于超星学习通的 Tampermonkey 用户脚本，**一键提取**随堂练习/章节测验中的题目、选项和正确答案，方便复习整理。

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击 Tampermonkey 图标 → "添加新脚本"
3. 将 `chaoxing-quiz-extractor.user.js` 的内容粘贴进去，保存
4. 完成

## 使用方法

1. 打开超星学习通中任意**已批改**的随堂练习/章节测验/作业页面（统计视图）
2. 页面右下角会出现一个蓝色浮动按钮 **「提取答案」**
3. 点击按钮，弹出面板展示所有题目和正确答案
4. 点击 **「复制全部」** 一键复制到剪贴板

## 功能

- 支持**单选题、多选题、判断题、填空题**
- 自动剥离统计信息（答题人数、正确率等），仅保留干净题干和选项
- 正确选项以 ✔ 标记
- 一键复制全部题目与答案
- 兼容超星学习通统计页、作业批改页等多种页面布局

## 注意事项

- 仅支持**已批改**（已显示正确答案）的页面提取
- 部分页面内容可能在 iframe 中，脚本已适配
- 提取结果仅供参考，请以课程内容为准
